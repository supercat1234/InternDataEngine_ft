# 8° 落盘、放置后回位与夹爪状态

当前任务执行顺序：左夹爪闭合启动 → 以 40 mm 总开度预抓 → 闭爪抓杯 → 搬运 → 松爪落盘并撤退 → 左臂回到本次起始关节位置 → 夹爪恢复闭合并最终复核杯子稳定性。

## 配置与行为

| 配置 | 当前值 | 含义 |
| --- | --- | --- |
| `robots.left_gripper_home` | [0.0] | 左夹爪主动单指初始位移为零，闭合启动 |
| `robots.planner_gripper_open_width` | 0.040 m | 规划模型两指总开度，对应两指关节 ±20 mm |
| Pick `pre_grasp_width` | 0.040 m | 预抓、松爪及回位途中使用的两指总开度 |
| Place `chain_place_tilts_deg` | 0/3/4/6/7° | 优先小倾角，新增 6°/7°候选，为 8°判据留余量 |
| Place / Verify `max_tilt_deg` | 8° | 落盘路径和最终杯子相对盘面的倾角上限 |
| Place / Verify `max_support_tilt_deg` | 5° | 盘子自身的倾角上限保持原值 |
| ReturnHome `planning_timeout_s` | 20 s | 回位路径检查/规划预算 |
| ReturnHome `joint_tolerance_deg` | 0.5° | 六关节最大绝对回位误差 |
| ReturnHome `stable_steps` | 3 | 回位关节误差连续达标帧数 |
| Verify `gripper_state` | -1 | 回位后恢复闭合并保持 |

初始化不仅设置关节位置，也同步设置驱动目标，保证闭合初始状态不被残留目标覆盖。右臂夹爪配置保留原值，本任务只操作左臂。

抓取标注已按 40 mm 重新生成，仍为 768 个原始标注。脚本默认值同步，也可显式执行：

```bash
bash scripts/isaac_python.sh scripts/assets/make_cup_grasp_labels.py --mode rim --rim-opening 0.040
```

回位目标来自初始规划前实际测得的六关节位置，而不是把机器人直接重置为零位。松爪和撤退完成后，将盘中的杯子重新纳入规划世界，优先检查平滑关节返回曲线，不能通过碰撞检查时再调用规划器。未检查的插值不会直接执行，路径不外推或越过回位目标。

新增独立的 `return_home` 技能，回位期间状态、动作和图像照常记录。必须执行完全部路径并连续满足关节精度后才通过，随后执行最终放置复核；回位失败不能保存为成功数据。

当前总开度已由 30 mm 更新到 40 mm，配置、规划模型与标注同步；下方物理成功样例为此前的 30 mm 配置，40 mm 尚未补跑完整物理验证。
